Production systems I've secured

Secure Order Delivery Portal

Order-delivery system on Cloudflare Workers, D1 and R2 that has processed 800+ orders. Customers verify their account before anything is delivered, and a bot fulfils one product line in under 2 minutes. Built to fail safely: token-authenticated WebSockets, idempotent processing so no order runs twice, crash recovery, and an automatic refund if an order isn't delivered within 2 days.

#Cloudflare Workers#D1#R2#WebSockets

Role-Based Access Control & OAuth Login

Owner, admin and user roles enforced at the database layer with PostgreSQL Row-Level Security, plus JWT checks across 30+ serverless functions, so each user only reaches the data their role allows. Passwordless login via Google and Discord OAuth.

#PostgreSQL RLS#JWT#OAuth

Payment & Webhook Security

Serverless functions that handle orders and payments. Incoming webhooks are verified with HMAC-SHA256 signatures using constant-time comparison to block timing attacks. Endpoints fail closed: a bad or missing signature is rejected, never waved through. Per-IP rate limiting, input validation and security headers including HSTS. Payments run through Stripe.

#HMAC-SHA256#HSTS#Rate limiting#Stripe

Monitoring & Alerting

Monitoring for my production systems, so I hear about failures from an alert, not a customer. Heartbeat watchdogs check that critical services are alive, real-time alerts fire when they aren't, and scheduled GitHub Actions open an issue automatically when a check fails — so every failure leaves a record to follow up on.

#Watchdogs#Alerting#GitHub Actions

Change-Controlled AI SEO Agent

An autonomous AI agent that works on the stores' SEO under strict change control. It can only ship changes as GitHub pull requests, then verifies the deploy and checks the live site. It is never allowed to touch the design. Every change is reviewable and reversible — how I think any automation in production should work.
