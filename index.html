AI systems that plan, use tools and prove the result

Generating text is the easy part. These systems take on multi-step work: they reason through a task, call tools, check what actually happened and stop at defined limits. Each one says where it really stands.

Multi-Agent Coding Coordinator

Give it a goal and a task list, and it runs up to six coding agents, Codex and Claude, in parallel. The hard problem is trust: an agent will happily report that its tests passed. So the coordinator, not the agent, decides when work is done.

Working prototype, validated in live runs. Not published yet.

  • TypeScript on Node
  • Claude Code
  • Codex
  • MCP
  • Git worktrees
  1. PlanTasks with dependencies, and each worker owns only its files
  2. BuildA worker writes the code in its own Git worktree
  3. ReviewA worker from the other provider must read the exact commit's diff
  4. VerifyChecks run as real processes the worker can't edit, on the candidate and the combined branch
  5. RepairFailures go back with the evidence, for up to three rounds, then the task is blocked with a report
  6. IntegrateOnly reviewed, verified work lands, with a clean rollback on conflict

A replay of how a failing task is handled. In the live demo, the access-control task failed a real test, and the corrected version passed.

  • A worker saying its tests passed counts for nothing. They have to pass in a real process.
  • Any change after approval voids it, and stale commits are refused.
  • Acceptance checks live outside the repo, and their hashes are compared before and after each run.
  • Peer messages can't grant new scope. A person can pause, message, retry or stop the team at any time.

On a real project it delivered five of six tasks. The sixth hit a provider safety block, and the coordinator reported it blocked rather than passing it.

    • Orchestration and tools

      Multi-step runs with task dependencies, strict tool schemas and per-tenant allowlists. The tenant is injected by code, never by the model.

    • Verification

      Agents don't grade themselves. Golden sets, trusted checks and real exit codes decide, and CI fails when results drop.

    • Human approval and limits

      Deny by default. High-impact tools wait for a person, code ships through pull requests, and a gateway outside the model enforces the limits.

    • Observability and audit

      Every tool call is logged and attributable, runs keep checksummed evidence, and audit trails can be HMAC-chained so tampering shows.

    • Models and providers

      I train models on Hugging Face datasets, and I build across Claude, Codex, Cursor and local models through Ollama, so a system isn't tied to one vendor's API.

    • Retrieval and state

      Hybrid search and reranking ground the answers, and conversation state lets follow-up questions resolve correctly.
